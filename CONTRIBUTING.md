# Contributing

Experimental and unmaintained; independent forks and a new maintainer are welcome. No guaranteed response, PR review or release commitment.

Use the pinned Python environment and debug Gradle build described in docs/BUILD_AND_TEST.md. Keep synthetic fixtures, deterministic score contracts and golden cases together. Changes to check-ins/profiles must preserve draft-versus-approved truth, missing/false/zero behavior, and independently verified storage consequences. Never commit diary data, exports, credentials, private addresses, signing material, APKs or caches. Preserve upstream notices; first-party code/tests are MIT licensed.
